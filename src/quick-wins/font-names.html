Quick win 33 of 34 · Look, feel and accessibility

What we're proposing

Rename the "Gilroy" font families to Poppins, which is what the site actually loads.

Why

The stylesheet registers families called GilroyRegular, GilroyBold and so on, but every one of them loads a Poppins file. It looks as if Gilroy was swapped out at some point and the names were left behind. Nobody visiting the site sees the difference, but the next developer or designer to work on it will be misled, so it is worth a small fix and a question about whether Gilroy is still the brand face in print.

Name the typeface correctly in the stylesheet

Rename the "Gilroy" font families to Poppins, which is what the site actually loads.

Switch between the site as it is and the change. Arrow keys work too.

TodayFamilies named Gilroy that load Poppins.

abpi.org.uk/assets/styles/styles.min.css
@font-face {
  font-family: GilroyBold;
  src: url("../../assets/fonts/Poppins/Poppins-Bold.ttf");
}
h1 { font-family: GilroyBold; }

ProposedFamilies named for the font they load.

abpi.org.uk/assets/styles/styles.min.css
@font-face {
  font-family: "Poppins";
  font-weight: 700;
  src: url("../../assets/fonts/Poppins/Poppins-Bold.woff2") format("woff2");
}
h1 { font-family: "Poppins", sans-serif; font-weight: 700; }
