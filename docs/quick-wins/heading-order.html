Quick win 34 of 34 · Look, feel and accessibility

What we're proposing

Fix the heading levels on the homepage so screen readers and search engines read the structure correctly.

Why

On the homepage, the main heading is followed by a level-3 strapline before the first level-2 heading, and card titles skip levels. People using screen readers navigate by headings, so the order matters to them. It is a template fix, and a natural part of an accessibility review.
