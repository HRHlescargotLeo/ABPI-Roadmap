Quick win 22 of 34 · Events

What we're proposing

Date, time, place and price in one panel, a plain booking button and a calendar file.

Why

Booking currently goes through a link that reads "VISIT THE WEBSITE HERE!" (on another event, "VISIT THE WEBSITE HERE TO BOOK!"), which doesn't say where it goes. A small panel with the essentials, a button that names the booking system and a calendar file is a template change.
